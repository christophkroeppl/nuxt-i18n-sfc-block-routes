# Changelog

## 0.1.0

Initial release.

### Features

- Extract i18n route paths from Vue SFC `<i18n>` custom blocks
- Support YAML and JSON block formats
- Auto-populate `nuxt.options.i18n.pages` for `@nuxtjs/i18n` integration
- Handle Nuxt route groups (parenthesized directories)
- Set `page.meta.i18n` during `pages:extend` hook
